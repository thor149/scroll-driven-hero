# General Preferences

- When given a reference implementation or demo to recreate, match it faithfully (layout, motion, and visual style) rather than expanding into extra screens, sections, or animations of my own invention. Confidence: 0.9
- Prefers restrained motion design: only the elements named in the spec should animate (e.g. car moves, boxes appear on scroll) — no added parallax, fades, or decorative animation beyond the reference. Confidence: 0.85
- Prefers the reference's own visual style (e.g. light canvas, green band, colored boxes) over a custom/premium reinterpretation when replicating a design. Confidence: 0.85
- Wants requirements checked against the reference and conflicts between written spec and the reference clarified via questions before rebuilding. Confidence: 0.75
